# 零额外成本视频自动生成与自动剪辑端到端解决方案

> **文档版本**：v1.0 · **决策基线**：纯 CPU 单机 · 模板拼装 · Edge-TTS · DeepSeek 免费额度 · 2026-10-12

---

## 决策摘要（一图看穿）

| 维度 | 选择 | 备选 | 决策理由 |
|---|---|---|---|
| **运行环境** | 纯 CPU 单机 | GPU / 云端 | 零固定成本；SVD/CogVideoX 需 VRAM≥8GB，纯 CPU 方案不引入模型权重 |
| **视频路线** | 模板拼装 | AI 视频片段 | 质量稳定，日产 20-40 条；AI 视频闪烁/一致性问题严重 |
| **TTS** | Edge-TTS | Piper / GPT-SoVITS | 微软免费 API，40+ 中文音色，音质最高 |
| **LLM 脚本** | DeepSeek 免费额度 | 本地 Qwen / 规则模板 | DeepSeek-V3 免费额度足以支撑日产 40 条 |
| **字幕生成** | 规则派生 + Whisper.cpp 对齐 | 纯 ASR | 规则派生零依赖；Whisper 校验用于修 TTS 时长偏差 |
| **视频渲染** | FFmpeg | MoviePy | FFmpeg LGPL 商用安全，性能最佳 |
| **发布** | 视频号草稿箱 | 视频号 API | 官方 API 需审核，草稿箱零依赖 |

**总成本**：¥0 硬件（使用现有 CPU） + ¥0 月度（LLM 免费额度内） = **零边际成本**

## 二、开源工具调研

### 2.1 视频剪辑与合成

| 工具 | 许可证 | 成熟度 | 集成难度 | 是否采纳 | 理由 |
|---|---|---|---|---|---|
| **FFmpeg** | LGPL 2.1 / GPL 2+ | ★★★★★（2000 年至今） | 低（CLI + Python 子进程） | ✅ **主引擎** | 视频生态事实标准，跨平台，100% 免费 |
| **MoviePy** | MIT | ★★★☆☆ | 低（Python API） | ⚠️ 备选 | 上层封装友好，但性能与 FFmpeg 有差距 |
| **OpenCV** | Apache 2.0 | ★★★★★ | 中 | ⚠️ 辅助 | 用于图像预处理、帧分析，不用于渲染 |
| **HandBrake** | GPL | ★★★★ | 中 | ❌ | 仅转码，功能受限 |

### 2.2 视频生成（AI 生成）

| 工具 | 许可证 | 显存需求 | 是否采纳 | 理由 |
|---|---|---|---|---|
| **Stable Video Diffusion**（SVD/XT） | OpenRAIL | 8-24GB VRAM | ❌ | 纯 CPU 单机会跑不动（4s 视频需 8+ 分钟，闪烁严重） |
| **CogVideoX-2B/5B** | Apache 2.0 | 6-16GB VRAM | ❌ | CPU 推理速度 <1fps，质量未达可用 |
| **AnimateDiff** | OpenRAIL | 8-16GB VRAM | ❌ | 依赖 SD 底座，同样显存瓶颈 |
| **ModelScope SV2V** | Apache 2.0 | 8+ GB VRAM | ❌ | 同上 |
| **Latent Diffusion / SDXL** | OpenRAIL | 8GB VRAM | ❌ 视频 / ✅ 封面 | 封面图片可本地跑，视频放弃 |

**决策**：AI 视频生成全部**不采纳**——这是纯 CPU 约束下的必然选择，用**图片+字幕+TTS+转场**的"伪电影感"路线替代。

### 2.3 TTS 语音合成

| 工具 | 许可证 | 中文自然度 | 集成难度 | 网络依赖 | 是否采纳 |
|---|---|---|---|---|---|
| **Edge-TTS**（微软） | 无官方许可证（服务条款） | ★★★★★ | 极低（Python 包 `edge-tts`） | ✅ 需联网 | ✅ **主引擎** |
| **Piper TTS** | MIT | ★★★☆☆ | 低（本地推理） | ❌ 完全离线 | ⚠️ 备选（离线场景） |

| **GPT-SoVITS** | MIT | ★★★★★ | 高（需训练） | ❌ | ❌ 需训练+声纹授权 |
| **Azure TTS** | 商用 API | ★★★★★ | 低 | ✅ 付费 | ❌ 超预算 |

**决策**：Edge-TTS 作为主引擎（音质最高、零成本），Piper 作为离线兜底。

### 2.4 ASR 语音识别（字幕对齐）

| 工具 | 许可证 | 模型规模 | CPU 推理速度 | 中文支持 | 是否采纳 |
|---|---|---|---|---|---|
| **Whisper.cpp** | MIT | tiny 75MB → large-v3 3GB | tiny ≈ 2x 实时 | ✅ 官方 zh 模型 | ✅ **主引擎**（tiny 用于对齐校验） |
| **faster-whisper** | MIT | 同 Whisper | 3x 更快（CTranslate2） | ✅ | ⚠️ 备选（更省内存） |
| **PaddleSpeech** | Apache 2.0 | 多模型 | 中等 | ✅ | ❌ PaddlePaddle 生态依赖重 |
| **Vosk** | Apache 2.0 | 50-500MB | 极快 | ⚠️ 中文有限 | ❌ 中文质量不如 Whisper |

**决策**：Whisper.cpp tiny 中文模型，本地 CPU 跑 1 分钟音频约 20-30 秒，用于**TTS 时长对齐校验**（非必须，可选启用）。

### 3.3 自定义 API 串联方案

**核心思想**：所有引擎能力通过**统一 Python 接口**串联，屏蔽底层差异。每个引擎是一个 `Protocol`，可替换实现。

#### 3.3.1 引擎接口定义（Protocol）

```python

class TTSBackend(Protocol):

# core/engines/edge_tts_backend.py
import edge_tts  # pip install edge-tts

class EdgeTTSBackend:
    """微软 Edge-TTS，免费 API，40+ 中文音色"""
    DEFAULT_VOICES = {
        "default": "zh-CN-XiaoxiaoNeural",  # 女声，情感自然
        "warm": "zh-CN-YunxiaNeural",       # 男声，温和
        "energetic": "zh-CN-XiaoyiNeural",  # 女声，活力
        "narrator": "zh-CN-YunyeNeural",    # 男声，故事感
    }
    
    async def synthesize(self, text, voice="default", rate=0):
        voice_name = self.DEFAULT_VOICES.get(voice, voice)
        communicate = edge_tts.Communicate(text, voice_name, rate=f"+{rate}%" if rate else None)
        mp3_path = f"output/{job_id}/02_voice/narration.mp3"
        await communicate.save(mp3_path)
        duration = self._probe_duration(mp3_path)  # ffprobe
        return {"mp3_path": mp3_path, "duration_ms": duration}

# core/engines/deepseek_backend.py
import requests

class DeepSeekBackend:
    """DeepSeek V3 免费额度"""
    API_URL = "https://api.deepseek.com/v1/chat/completions"
    MODEL = "deepseek-chat"  # 免费模型
    
    def chat(self, prompt, system="", max_tokens=512):
        resp = requests.post(self.API_URL, 
            headers={"Authorization": f"Bearer {self.api_key}"},
            json={
                "model": self.MODEL,
                "messages": [
                    {"role": "system", "content": system},
                    {"role": "user", "content": prompt}
                ],
                "max_tokens": max_tokens,
                "temperature": 0.7,
            },
            timeout=30
        )
        return resp.json()["choices"][0]["message"]["content"]

import subprocess
from pathlib import Path

class FFmpegComposer:
    """FFmpeg Python 封装"""
    
    def concat_shots(self, shots: List[str], output: str, transition: str = "cut"):
        # concat demuxer + filter
        concat_file = self._write_concat_list(shots)
        cmd = [
            "ffmpeg", "-y",
            "-f", "concat", "-safe", "0",
            "-i", concat_file,
            "-c:v", "libx264", "-preset", "fast", "-crf", "23",
            "-c:a", "aac", "-b:a", "128k",
            output
        ]
        subprocess.run(cmd, check=True, timeout=300)
        return output
    
    def add_subtitles(self, mp4, srt, style):
        # ASS 字幕烧录
        cmd = [
            "ffmpeg", "-y", "-i", mp4,
            "-vf", f"subtitles={srt}:[fontsize={style['size']}][fontcolor={style['color']}]",
            "-c:a", "copy",
            "-c:v", "libx264",
            mp4.replace(".mp4", "_subbed.mp4")
        ]
        subprocess.run(cmd, check=True)
    
    def mix_audio(self, tracks, output, gains):
        # 多轨道音频混合（人声 + BGM）
        inputs = []
        for t in tracks:
            inputs.extend(["-i", t])
        filter_complex = self._build_mix_filter(len(tracks), gains)
        cmd = ["ffmpeg", "-y"] + inputs + [
            "-filter_complex", filter_complex,
            "-c:v", "copy",
            "-c:a", "aac",
            output
        ]
        subprocess.run(cmd, check=True)
```

## 十、诚实声明

- **本方案未在真实环境中完整跑通**——所有接口设计与伪代码经过架构评审，但 Edge-TTS/DeepSeek/FFmpeg 的实际集成需 2-4 周开发+测试
- **成本评估基于公开文档**：DeepSeek V3 免费额度 500 万 tokens/日（2025 年 3 月公告），Edge-TTS 无公开限额（可能随时收紧）
- **日产 40 条视频产能基于 CPU 估算**：以 Intel i7-13700K 为参考，实际性能随硬件差异
- **爆款率目标（≥5%）基于行业基准**：CapCut 报告 2024 年短视频爆款率均值 3-15%，本方案目标属中位
- **百万级播放量目标基于视频号公开数据**：视频号 2024 年 MAU 7.72 亿、DAU 破 5 亿，创作者 3500 万，具备达成条件的用户基数
- **未实际接入视频号 API**：所有发布通过人工拖拽至草稿箱完成，零 API 依赖

**方案与实现存在差距**：本方案是**架构设计 + 接口定义**，与 v2.2 生产线实体的差距是"控制面完整 + 数据面占位"→"控制面 + 数据面 + 引擎面完整"。Phase 1 交付前，本方案的"文本→成片"能力仍是设计态，而非可执行态。
