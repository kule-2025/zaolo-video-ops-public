## 二、3D 图标体系（Agnes 生成 + CSS 3D 增强）

### 2.1 Agnes 3D 图标（10 张）

采用 `agnes-image-2.1-flash` 模型生成，512×512 PNG，风格统一：
- **主色渐变**：`#4A14E8 → #7A3CFF → #FF6A1A`（品牌紫→亮紫→橙）
- **副色点缀**：`#06C78A` 薄荷、`#FFB703` 琥珀、`#4A14E8` 深紫
- **光影**：柔和棚拍光，白色底 + 底部阴影
- **造型**：3D isometric 等距视角，几何化简洁

### 2.2 SVG symbol 库（27 个）

内联到 `prototype/index.html` `<body>` 开头，`viewBox 24×24`，`stroke=currentColor`，通过 CSS 变量控制颜色，`<use href="#ic-xxx"/>` 复用：

- **主导航 10**：ic-arch / ic-pipeline / ic-swarm / ic-rsi / ic-engines / ic-scoring / ic-compliance / ic-modules / ic-dataflow / ic-production
- **阶段 8**：ic-s1 ~ ic-s8（S1 需求 → S8 评论）
- **通用 9**：ic-refresh / ic-copy / ic-search / ic-info / ic-warn / ic-check / ic-x / ic-sparkle / ic-gear

### 2.3 CSS 3D 视觉增强

在原型内联 `<style>` 中新增 ~350 行 3D 增强规则：

- **导航 3D PNG**：`drop-shadow` 品牌紫阴影，hover 上浮 -2px + 旋转 -2°
- **卡片 3D**：三层阴影 `0 1px 2px + 0 4px 12px + inset` + 顶部白色高光条
- **KPI 数字渐变**：`background-clip: text` 使数值着色为品牌渐变
- **按钮 3D 按压**：`box-shadow: 0 2px 0 品牌紫` 阴影下沉效果
- **Stage 卡片**：linear-gradient 立体底 + inset shadow
- **Metro 节点**：hover 上浮 + 缩放 1.05x
- **Grade 徽章**：text-shadow 立体 + inset 内阴影
- **Toast**：`backdrop-filter: blur` 玻璃质感
- **Progress 条**：立体渐变 + 顶部白高光
- **Agent/Variant/Cycle/Gate 卡片**：全套 3D 化

## 七、性能优化

### 7.1 已实施优化

| 优化项 | 实现 | 收益 |
|---|---|---|
| SVG sprite | 27 个 symbol 单次定义，多处 `<use>` 复用 | DOM 减少 ~70% 图标节点 |
| 3D PNG 懒加载 | 所有 `<img>` 加 `loading="lazy"` + `decoding="async"` | 首屏不阻塞 |
| 事件代理 | nav-item 事件代理，减少监听器 | 页面切换无抖动 |
| 懒初始化 | `onPageActivate` 首次访问才挂载 Copy 按钮 | 首屏更快 |
| CSS 精简 | 单一 `<style>` 块，无外部请求 | 无跨域 CSS 请求 |
| 图片体积 | 3D PNG 512×512，750 KB 每张 | 视觉细节足够，体积可控 |
| 首屏可见性 | `<script>` 全部延后到 body 末尾 | 首屏 paint 时间提前 |

### 7.2 性能指标

- **首屏 HTML 体积**：172 KB（含 3 个内联 `<script>` + 27 个 symbol + 全部样式）
- **3D PNG 总大小**：约 8.1 MB（10 张，均懒加载，非首屏页图标不参与首屏加载）
- **首屏渲染关键资源**：仅 `index.html` + 2 张首屏图标（arch + 当前激活页）
- **无外部 CSS/JS 依赖**：零 CDN，零外链
