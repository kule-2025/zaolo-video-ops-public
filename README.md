# ZAOLO 造流 · 视频号运营助手

**版本 v2.11.0** · 2026-10-13

面向内容创作者与运营团队的视频号一站式运营平台，把「内容生产 → 合规审核 → 发布分发 → 数据回流 → 策略进化」全链路整合为一个可运行的产品。

> 本仓库为**公共文档仓库**，仅提供产品介绍、品牌规范与变更记录。完整源码为私有分发，不在此处公开。

---

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 数字员工蜂群 | 合同网招标式任务调度，多角色并行执行内容流水线各阶段 |
| RSI 自进化闭环 | 观测 → 诊断 → 假设 → 变异 → 实验 → 选择 → 固化，策略持续自我优化 |
| 内容引流引擎 | 问题簇生成 + 多渠道引流计划，覆盖搜索、社群、私域场景 |
| 爆款潜力评估 | 10 维加权评分 + ABCD 等级，对选题进行发布前潜力预测 |
| 合规红线闸门 | 多级词库分级扫描（高危/中危），在发布前拦截违规风险 |
| 数据流引擎 | DF1-DF7 七条标准化数据流，贯通账号、视频、分镜、对话、质检、成本、发布回流 |
| 价值链引擎 | V1-V6 六环价值链，量化各环节投入产出与转化 |
| 生产线实体 | 脚本、分镜、时间线、字幕、封面、剪辑指令的端到端生成 |
