## 三、色板使用纪律

| 令牌 | 用途纪律 | 禁用 |
| --- | --- | --- |
| `--brand` #4A14E8 | CTA 主按钮 / 品牌强调 / 大字标题 | 不作正文文字（对比度不足） |
| `--brand-2` #7A3CFF | 渐变中段 / hover 色 / 次强调 | 单用（须搭配品牌主色） |
| `--accent` #FF6A1A | 点缀 / HOT 标记 / 关键 CTA | 大面积底色 |
| `--mint` #06C78A | 成功 / 通过 / 已发布 | 用于危险态 |
| `--coral` #E63946 | 危险 / 拦截 / 失败 | 大面积底色 |
| `--amber` #FFB703 | 警告 / 待处理 / B 级评分 | 单独作为 CTA |
| `--ink` #0F0F23 | 主文字 / 深色底 | 作强调 |

**对比度纪律**：
- `#22c55e` 类浅绿 → 仅作 ≥18px 大字或按钮底
- 正文文字用 `--ink` / `--ink-2`
- 品牌主色 `#4A14E8` 在白底上对比度 ≥ 8:1，可用作文字

## 四、Logo 使用规范（禁则）

1. **不加描边、投影、浮雕、外发光**
2. **不改变渐变方向**（恒 135°）
3. **不与涟漪/流辅助图形混排**在同一 Logo 位
4. **不使用未收录于本 README 的变形版本**
5. **图形四周安全边距 ≥ 图形高度 25%**
6. **单色稿优先用于印刷、微信状态栏、系统任务栏**
7. **社媒头像用 icon.svg（圆形裁切友好）**

## 六、动效原则

| 场景 | 动作 | 时长 |
| --- | --- | --- |
| 页面切换 | fade + translateY(6px) | 300ms / ease |
| 按钮 hover | brightness(1.05) + translateY(-1px) | 200ms |
| 流程节点运行中 | 脉冲 box-shadow | 1.5s infinite |
| Logo | 不参与动画 | — |
| 全局 | prefers-reduced-motion 全关 | — |

**克制原则**：Logo 自身静默，动效仅出现在页面级状态和按钮交互。

## 七、前后端契约约定

1. 所有前端可视字段必须标注 `data-bind="<backend.path>"`（如 `data-bind="dashboard.kpi.today_output"`）
2. 品牌令牌通过 `theme.css` + `ui_tokens.json` 双通道传递
3. 后端返回的状态字段（`done`/`run`/`warn`/`fail`）与前端 `.zaolo-pnode.*` 类严格对应
4. 等级字段（`S`/`A`/`B`/`C`）与 `.zaolo-pill-*` 严格对应
5. 详细字段映射见 `core/contracts/ui_bindings.json`（Phase E 产出）
